## 🚀 Key Features

* **📱 Multi-Page SPA Navigation:** Ultra-smooth tab navigation between Home, Courses, Faculty Panels, E-Books, and Classroom.
* **🛡️ Two-Step Admin Security Gate:** Decoy captcha + secret authentication passcode with dedicated administrative dashboard.
* **🔒 Single Active Device Protection:** Watchdog engine utilizing `BroadcastChannel` and `localStorage` to prevent account sharing and enforce 1-device-per-user security.
* **👨‍🏫 Interactive Faculty Panels:** Filter by Online/Offline, SSC/HSC, and Science/Business Studies.
* **💻 Signature Developer Highlight:** Dynamic green glow highlight effect on developer faculty card.
* **🌐 Google Schema & SEO:** Full Schema.org JSON-LD Structured Data, Open Graph cards, and Twitter cards.
